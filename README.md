# My Tasks

A responsive task-management web app built with plain HTML, CSS, and JavaScript.

## Features

- Add tasks
- Mark tasks complete / reopen them
- Delete tasks with confirmation
- Clear completed tasks
- Progress percentage
- Light / dark mode
- Data persistence using browser `localStorage`
- Responsive mobile layout
- No backend required

## Technologies / Libraries

This project does **not require any external libraries or frameworks**.

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage API
- Inline SVG icons

Because there are no external dependencies, you can deploy it directly with GitHub Pages.

## GitHub Pages deployment

1. Create a GitHub repository, for example: `my-tasks`.
2. Upload `index.html` and this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
